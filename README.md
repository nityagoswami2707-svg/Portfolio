# Nitya Goswami — Portfolio v2

A responsive dark editorial / technical portfolio inspired by the reference site's structured developer layout, project showcase, toolkit and activity timeline. It is an original design, not a copy.

## Quick Start (Vite Dev Server)

```bash
# 1. Install dependencies (already installed)
npm install

# 2. Start local development server with hot-reload
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build locally
npm run preview
```

Server runs on: [http://localhost:5173](http://localhost:5173)

## Run in VS Code
1. Open the `nitya-portfolio-v2` folder in VS Code.
2. Run `npm run dev` in the terminal, or press `Ctrl + Shift + B` to run the dev task.
3. Open `http://localhost:5173` in your browser.

## Files
- `index.html` — content and sections
- `style.css` — design, layout and responsive styles
- `script.js` — mobile navigation
- `assets/nitya-profile.jpeg` — profile photo

## Edit
Update text and links in `index.html`; change colors and spacing in `style.css`.
Project descriptions are concise summaries; verify implementation details against the linked repositories before publishing.
